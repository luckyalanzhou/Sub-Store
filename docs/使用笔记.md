# 使用笔记

在 LuCI 的「服务 → sub-store」顶部查看状态，在页面底部执行容器操作。

首次运行 `.run` 安装插件后，服务状态为「尚未安装」。点击「安装」才会准备镜像并启动容器。

| 状态 | 可用操作 |
| --- | --- |
| 尚未安装 | 安装 |
| 运行中 | 升级/应用、停止、重启 |
| 已停止 | 升级/应用、启动、删除 |

「安装」和「升级/应用」会保存并应用表单设置。「升级/应用」分别检查镜像和插件版本。容器配置有变化时会重新部署，原先停止的容器会在健康检查后恢复停止状态。操作进度和结果可在「日志 → 维护日志」查看。

「删除」需要确认，只删除已停止且有独立数据挂载的容器。镜像同时满足官方仓库归属明确、没有其他仓库引用、没有其他容器使用时，才会尝试清理。UCI 配置和持久化数据会保留，可再次点击「安装」恢复服务。

「镜像」写入 UCI 的 `sub-store.main.image`，默认值为 `xream/sub-store:latest`，也支持该官方仓库的标签或 SHA-256 摘要。「API 密钥」写入 `sub-store.main.api_path`，须为 48 位十六进制字符。设备脚本在部署时重新校验这些设置。
